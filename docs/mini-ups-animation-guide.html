۱. ایده کلی: چه چیزی داریم می‌سازیم؟

به‌جای ساختن شکل‌ها با دست در کد، یک فایل سه‌بعدی آماده به نام mini-ups.glb را در مرورگر نمایش می‌دهیم. این فایل از اسکریپت پایتون build_mini_ups.py ساخته شده و شامل قطعات نام‌گذاری‌شده است؛ مثل درب، باتری، برد شارژر و پورت‌ها.

هدف نهایی صفحه اصلی:
  • نمایش مدل واقعی محصول با جزئیات
  • چرخش آهسته خودکار
  • باز و بسته‌شدن قطعات (Exploded View)
  • هاور روی هر قطعه و نمایش نام/توضیح فارسی
  • چرخش دستی با درگ موس (OrbitControls)

۲. نقش هر کتابخانه

کتابخانه کارش چیست؟ در این پروژه کجا استفاده شد؟
three موتور سه‌بعدی مرورگر: مش، متریال، نور، دوربین رنگ‌ها، متریال‌ها، پیدا کردن آبجکت‌ها با نام، تغییر موقعیت قطعات
@react-three/fiber پل بین React و Three.js؛ صحنه را مثل JSX می‌نویسید Canvas، useFrame، eventهای pointer
@react-three/drei ابزارهای آماده روی Fiber useGLTF، OrbitControls، Environment، ContactShadows
next فریمورک React برای وب صفحه اصلی App Router و سرو کردن فایل GLB از پوشه public
نکته مهم: React Three Fiber مثل React معمولی است، فقط به‌جای div و button با چیزهایی مثل mesh، group و ambientLight کار می‌کنید.

۴. جریان اجرا از صفحه اصلی تا صحنه سه‌بعدی

کاربر صفحه را باز می‌کند

app/page.tsx کامپوننت MiniUpsScene را رندر می‌کند.

Canvas ساخته می‌شود

Fiber یک <canvas> می‌سازد و حلقه رندر Three.js را راه می‌اندازد. از این لحظه، هر فریم صفحه (حدود ۶۰ بار در ثانیه) می‌تواند انیمیشن را آپدیت کند.

مدل GLB لود می‌شود

useGLTF("/mini-ups.glb") فایل را از public/mini-ups.glb می‌گیرد و درخت آبجکت‌ها را آماده می‌کند.

هر فریم انیمیشن اجرا می‌شود

داخل useFrame مقدار Explode محاسبه می‌شود، موقعیت درب/باتری/بردها جابه‌جا می‌شود و LEDها چشمک می‌زنند.

هاور موس

وقتی موس روی یک مش می‌رود، نام قطعه از درخت والدین پیدا می‌شود، توضیح فارسی از partInfo.ts خوانده می‌شود، و یک باکس HTML کنار نشانگر موس نشان داده می‌شود.

۵. توضیح فایل‌به‌فایل کد

۵.۱ صفحه اصلی — app/page.tsx

import { MiniUpsScene } from "@/components/mini-ups/MiniUpsScene";

export default function Home() {
  return (
    <main className="relative h-dvh w-full overflow-hidden bg-[#0c1118]">
      <MiniUpsScene />
    </main>
  );
}
  • h-dvh: ارتفاع کامل ویوپورت (تمام صفحه).
  • صفحه عمداً خیلی ساده است؛ همه منطق سه‌بعدی داخل کامپوننت صحنه است.
  • رنگ پس‌زمینه تیره با فضای استودیوی محصول هماهنگ است.

۵.۲ دیکشنری قطعات — partInfo.ts

این فایل داده است، نه انیمیشن. هر قطعه مهم مدل یک id (همان نام نود داخل GLB)، یک عنوان فارسی و یک توضیح کوتاه دارد. 

export type PartInfo = {
  id: string;
  title: string;
  description: string;
};

// مثال:
{
  id: "Port_DC_OUT",
  title: "خروجی DC",
  description: "جک خروجی تغذیه DC دستگاه",
}

تابع‌های مهم:

  • resolvePartInfo(name): از روی نام یک مش/گروه، بهترین توضیح را پیدا می‌کند. اول نام‌های خاص‌تر را چک می‌کند تا مثلاً Port_PoE_1_Contact_3 به‌اشتباه «کل پورت‌ها» نشود.
  • resolvePartFromObject(object): از خود مش به سمت والدین بالا می‌رود تا به گروهی برسد که در دیکشنری تعریف شده (مثل Output_Buck_Converter).
اگر قطعه جدیدی به مدل اضافه کردید، فقط کافی است یک ردیف به آرایه PARTS اضافه کنید. نیازی نیست کل انیمیشن را عوض کنید.

۵.۳ لود مدل و تعامل — MiniUpsModel.tsx

این فایل قلب مدل است.

الف) لود و کلون کردن GLB

const { scene } = useGLTF("/mini-ups.glb");
const root = useMemo(() => scene.clone(true), [scene]);
  • useGLTF: لودر آماده Drei برای glTF/GLB.
  • clone(true): یک کپی عمیق از صحنه می‌سازد تا متریال/وضعیت این صفحه، cache سراسری لودر را خراب نکند.
  • فایل باید داخل public/ باشد تا با آدرس /mini-ups.glb در دسترس باشد.

ب) پیدا کردن گروه‌های اصلی برای Explode

lid.current = root.getObjectByName("Case_Top");
battery.current = root.getObjectByName("Battery_Pack");
charger.current = root.getObjectByName("PCB_Charger");
output.current = root.getObjectByName("PCB_Output");
ports.current = root.getObjectByName("Ports");

این نام‌ها دقیقاً از ساختار خروجی build_mini_ups.py آمده‌اند. وقتی گروه را جابه‌جا می‌کنید، همه فرزندانش (مثلاً LEDهای روی درب) با آن حرکت می‌کنند.

ج) متد خارجی setExplode

useImperativeHandle(ref, () => ({
  setExplode(value: number) {
    const e = value; // بین 0 تا 1
    lid.current.position.y = e * 0.055;
    battery.current.position.y = e * 0.028;
    charger.current.position.x = -e * 0.045;
    output.current.position.x = e * 0.045;
    ports.current.position.z = e * 0.038;
  },
}));
  • 0 = حالت بسته/مونتاژ شده
  • 1 = حداکثر بازشدگی Exploded
  • forwardRef + useImperativeHandle اجازه می‌دهد والد (صحنه) هر فریم این متد را صدا بزند، بدون اینکه کل مدل را با state سنگین re-render کند.

د) چشمک زدن LED

useFrame((state) => {
  const t = state.clock.elapsedTime;
  ledMats.current.forEach((mat, j) => {
    mat.emissiveIntensity =
      0.4 + (0.55 + Math.sin(t * 2.4 - j * 0.7) * 0.45) * 0.95;
  });
});

useFrame هر فریم اجرا می‌شود. با sin شدت نور خودتابش (emissive) را بالا و پایین می‌بریم. فاز متفاوت برای هر LED باعث می‌شود یکی‌یکی چشمک بزنند.

ه) هاور، هایلایت و callback

<primitive
  object={root}
  onPointerOver={(event) => {
    event.stopPropagation();
    const info = resolvePartFromObject(event.object);
    applyHighlight(findHighlightRoot(event.object, info.id));
    onHoverChange(info);
  }}
  onPointerOut={() => {
    clearHighlight();
    onHoverChange(null);
  }}
/>
  • primitive: یک آبجکت Three.js آماده را داخل JSX می‌گذارد.
  • onPointerOver/Out: eventهای Fiber روی مش‌ها (با raycasting).
  • applyHighlight: رنگ emissive قطعه را آبی روشن می‌کند تا کاربر بفهمد روی کدام بخش است.
  • onHoverChange: اطلاعات را به لایه HTML بیرون Canvas می‌فرستد تا Tooltip ساخته شود.

۵.۴ صحنه، نور و Tooltip — MiniUpsScene.tsx

الف) Canvas

<Canvas
  camera={{ position: [0.24, 0.16, 0.3], fov: 34, near: 0.01, far: 10 }}
  dpr={[1, 2]}
  gl={{ antialias: true, alpha: false }}
>
  <SceneContent ... />
</Canvas>
  • camera.position: جای دوربین نسبت به مدل (مدل مترمقیاس است، حدود ۱۸ سانتی‌متر).
  • fov: زاویه دید؛ عدد کمتر = زوم سینمایی‌تر.
  • dpr: کیفیت رندر روی صفحه‌های Retina.

ب) نور و محیط

کامپوننت کاربرد
ambientLight نور نرم همه‌جا؛ سایه‌های خیلی سیاه را کم می‌کند
directionalLight نور جهت‌دار مثل نور خورشید/استودیو
spotLight تاکید موضعی روی محصول
Environment انعکاس محیطی HDR برای فلز و پلاستیک واقعی‌تر
ContactShadows سایه نرم زیر محصول؛ حس نشستن روی سطح می‌دهد
OrbitControls درگ برای چرخاندن دوربین دور محصول

ج) انیمیشن چرخش و Explode در AnimatedUps

useFrame((state) => {
  const t = state.clock.elapsedTime;
  const cycle = 12;                 // مدت یک دور کامل (ثانیه)
  const phase = (t % cycle) / cycle; // 0 تا 1

  // timeline:
  // بسته → باز شدن → توقف → جمع شدن → بسته
  let e = 0;
  if (phase < 0.16) e = 0;
  else if (phase < 0.4) e = (phase - 0.16) / 0.24;
  else if (phase < 0.62) e = 1;
  else if (phase < 0.86) e = 1 - (phase - 0.62) / 0.24;
  else e = 0;

  const smooth = e * e * (3 - 2 * e); // smoothstep
  model.current?.setExplode(smooth);

  if (root.current && !pauseRef.current) {
    root.current.rotation.y = t * 0.18;          // چرخش آهسته
    root.current.position.y = Math.sin(t * 0.9) * 0.003; // شناوری خیلی کم
  }
});
smoothstep چیست؟

فرمول e*e*(3-2*e) حرکت را نرم می‌کند؛ یعنی بازشدن/بسته شدن با شتاب نرم شروع و تمام می‌شود، نه خطی و خشک.

د) Tooltip HTML بیرون Canvas

{hover ? (
  <div
    className="... باکس کوچک ..."
    style={{ left: cursor.x + 16, top: cursor.y - 56 }}
    dir="rtl"
  >
    <p>{hover.title}</p>
    <p>{hover.description}</p>
  </div>
) : null}
  • چرا بیرون Canvas؟ چون متن فارسی، فونت و استایل Tailwind روی HTML خیلی ساده‌تر و خواناتر است.
  • موقعیت باکس از مختصات موس داخل ظرف صحنه محاسبه می‌شود.
  • وقتی هاور فعال است، چرخش خودکار pause می‌شود تا خواندن راحت‌تر باشد.

۶. انیمیشن Explode چطور کار می‌کند؟

به‌زبان ساده:

  1. ساعت داخلی Three یک عدد زمان می‌دهد: elapsedTime
  2. آن را به یک چرخه ۱۲ ثانیه‌ای تبدیل می‌کنیم
  3. در هر بخش چرخه، عدد e بین ۰ و ۱ ساخته می‌شود
  4. همان عدد به موقعیت محورهای X/Y/Z گروه‌ها ضرب می‌شود
گروه جهت حرکت هنگام Explode چرا؟
Case_Top بالا (+Y) درب از بدنه جدا شود
Battery_Pack بالا (+Y) کمتر از درب پک باتری دیده شود
PCB_Charger چپ (−X) برد شارژر از مرکز خارج شود
PCB_Output راست (+X) برد خروجی جدا دیده شود
Ports جلو (+Z) پورت‌ها از پنل جلو بیرون بیایند

۷. هاور و Tooltip چطور کار می‌کند؟

Raycasting

Fiber از محل موس یک پرتو مجازی به صحنه می‌فرستد و می‌فهمد کدام مثلث/مش زیر نشانگر است.

حل نام قطعه

مش برخوردشده ممکن است جزئی مثل یک پیچ یا پین باشد. با بالا رفتن در درخت والدین، به نام معنادارتر می‌رسیم.

هایلایت

emissive متریال آن گروه موقتاً آبی می‌شود. هنگام خروج موس، مقدار قبلی برمی‌گردد.

نمایش باکس

state هاور در MiniUpsScene ست می‌شود و یک div فارسی کنار موس ظاهر می‌شود.

۸. نکات مهم برای تغییر و توسعه

اگر مدل را عوض کردید
  1. فایل جدید را در public/mini-ups.glb کپی کنید
  2. نام گروه‌های اصلی Explode را چک کنید
  3. در صورت نیاز partInfo.ts را به‌روز کنید
اگر می‌خواهید Explode دستی شود

به‌جای محاسبه از روی زمان، یک اسلایدر UI بسازید و مقدار ۰ تا ۱ را مستقیم به setExplode بدهید.

اگر می‌خواهید اسکرول‌محور شود (GSAP/ScrollTrigger)

طبق نکته اولیه پروژه، GSAP فقط وقتی لازم است که روایت سینمایی/اسکرول بخواهید. در آن حالت مقدار Explode را به progress اسکرول وصل می‌کنید.

چرا بعضی کامپوننت‌ها "use client" دارند؟

چون Canvas، event موس و useFrame فقط در مرورگر معنا دارند. در Next.js App Router باید این بخش‌ها Client Component باشند.

۹. خلاصه یک‌خطی برای به‌خاطر سپردن

  • Three.js = موتور سه‌بعدی
  • Fiber = نوشتن همان موتور به زبان React
  • Drei = ابزارهای آماده (لود GLB، کنترل دوربین، سایه، محیط)
  • GLB = خود محصول با قطعات نام‌دار
  • useFrame = قلب انیمیشن در هر فریم
  • partInfo = معنی فارسی هر قطعه برای Tooltip
